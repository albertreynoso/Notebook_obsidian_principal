**Consideraciones Metodológicas Adicionales:**

1.  **Enfoque de Medición:** Para la VI (Funcionalidad), los indicadores se obtendrán principalmente de los **logs del sistema**, lo cual representa una medición objetiva y constante de la "Aplicación de la Ingeniería".
2.  **Diseño Pre-test/Post-test:** La medición del **Desempeño Económico (VD)**, especialmente en las dimensiones de Ingresos y Reducción de intermediarios, debe realizarse comparando la data recolectada *antes* (O1) y *después* (O2) de la implementación y el uso de la plataforma.
3.  **Instrumentos:** La matriz refleja que se utilizará el **sistema de registro de logs** integrado en la plataforma (como instrumento principal para la VI y métricas de la VD), complementado posiblemente con un **cuestionario** (para las mediciones subjetivas de satisfacción o dependencia).

                  fillOpacity={period.isCurrent ? 0.5 : 0.2}
                  stroke={selectedCard.color}
                  strokeOpacity={0.3}
                  strokeWidth={1}
                />
              );
            })}

            {/* Líneas de separación de meses */}
            {chartData.filter(d => d.isNewMonth).map((d, idx) => (
              <ReferenceLine
                key={`month-${idx}`}
                x={d.day}
                stroke="#9ca3af"
                strokeDasharray="5 5"
                strokeWidth={1}
                label={{
                  value: d.month.toUpperCase(),
                  position: 'top',
                  fill: '#6b7280',
                  fontSize: 11,
                  fontWeight: 'bold'
                }}
              />
            ))}

            {/* Línea de "Hoy" */}
            <ReferenceLine
              x={0}
              stroke="#f59e0b"
              strokeWidth={3}
              label={{
                value: 'HOY',
                position: 'top',
                fill: '#f59e0b',
                fontSize: 12,
                fontWeight: 'bold'
              }}
            />

            {/* Líneas de fechas de facturación - POSICIÓN INFERIOR */}
            {billingPeriods.map((period, idx) => {
              const billingDay = getDayPosition(period.start);
              if (billingDay < -30 || billingDay > 30) return null;
              
              return (
                <ReferenceLine
                  key={`billing-${idx}`}
                  x={billingDay}
                  stroke="#3b82f6"
                  strokeWidth={2}
                  strokeDasharray="5 5"
                  label={{
                    value: `📅 Facturación`,
                    position: 'insideBottomLeft',
                    fill: '#3b82f6',
                    fontSize: 10,
                    offset: 10
                  }}
                />
              );
            })}

            {/* Líneas de fechas de pago - POSICIÓN INFERIOR */}
            {billingPeriods.map((period, idx) => {
              const paymentDay = getDayPosition(period.paymentDate);
              if (paymentDay < -30 || paymentDay > 30) return null;
              
              return (
                <ReferenceLine
                  key={`payment-${idx}`}
                  x={paymentDay}
                  stroke="#ef4444"
                  strokeWidth={2}
                  strokeDasharray="5 5"
                  label={{
                    value: `💳 Pago`,
                    position: 'insideBottomRight',
                    fill: '#ef4444',
                    fontSize: 10,
                    offset: 10
                  }}
                />
              );
            })}

            <XAxis
              dataKey="day"
              tickFormatter={(value) => {
                const item = chartData.find(d => d.day === value);
                return item ? item.dateLabel : value;
              }}
              tick={{ fontSize: 11 }}
              label={{ value: 'Días (centrado en HOY)', position: 'insideBottom', offset: -45, fontSize: 12 }}
            />

            <YAxis
              tick={{ fontSize: 11 }}
              label={{ value: 'Consumo Acumulado ($)', angle: -90, position: 'insideLeft', fontSize: 12 }}
              domain={[0, 'auto']}
            />

            <Tooltip content={<CustomTooltip />} />

            {/* Área bajo la línea */}
            <Area
              type="monotone"
              dataKey="cumulativeAmount"
              stroke="none"
              fill={`url(#gradient-${selectedCard.id})`}
            />

            {/* Línea de consumo real (solo hasta hoy) */}
            <Line
              type="monotone"
              dataKey="cumulativeAmount"
              stroke={selectedCard.color}
              strokeWidth={3}
              dot={false}
              activeDot={{ r: 6 }}
              connectNulls={false}
            />
          </LineChart>
        </ResponsiveContainer>
      </div>
    </div>
  );
};

export default CardConsumptionChart;
